
# FIFA World Cup 2026 Match Predictor

A machine learning-based prediction model for the 2026 FIFA World Cup, utilizing Elo ratings and historical match performance to forecast match outcomes.


## Features

- Dynamic Training: The model incorporates historical data + live tournament results to improve accuracy as the competition progresses.
- Probabilistic Outcomes: Spits out percentages for Home Win, Draw, and Away Win.
- Elo-Based Logic: Uses real historical Elo ratings to gauge team strength.


## Installation

- Prerequisites: Python 3.x, pandas, scikit-learn, openpyxl.

- Instructions:

  1. Clone the repo.

  2. Ensure your world_cup_data.xlsx is inside the /data folder.

  3. Run python predictor.py in your terminal.
